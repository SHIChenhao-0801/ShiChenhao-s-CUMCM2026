# 与核心源码对应的离散方程

此文件解释便携代码的计算定义，便于核对 `dryingCore.py`。它没有引入新模型或新的计算结果；完整论文和支撑中的检验证据应一并阅读。

材料坐标取 $x=r/R(t)$，节点为 $x_i=i/N$，内部控制体面为相邻节点中点，中心/表面控制体面分别为0与1。令

\[
w_i=\frac{x_{i+1/2}^2-x_{i-1/2}^2}{2},\qquad
\sum_i w_i=\frac12.
\]

状态按 $T_0,C_0,T_1,C_1,\ldots,T_N,C_N,L$ 交错排列。$L$为累计平均失水量，与$C$同为干基口径。初值为301.15 K、2.55及0。

代码中的面量 `heatG` 和 `waterG` 已含圆柱径向面权重$x_{i+1/2}$。热侧内部面取导热系数调和平均：

\[
G^T_{i+1/2}=x_{i+1/2}\,k_{i+1/2}
\frac{T_{i+1}-T_i}{\Delta x}.
\]

水侧正式方案为Kirchhoff势差。写$D=D_0 a_T\exp(-a/C)$，其中Q1的$a_T=1$，Q23/Q4的$a_T=\exp[-3850/T_{i+1/2}]$，面温度取相邻节点平均。势函数及内部面量为

\[
\Phi_a(C)=C\exp(-a/C)+a\,\operatorname{Ei}(-a/C),\qquad
\Phi_a'(C)=\exp(-a/C),
\]

\[
G^C_{i+1/2}=x_{i+1/2}D_0 a_T
\frac{\Phi_a(C_{i+1})-\Phi_a(C_i)}{\Delta x}.
\]

温度因子在同一个面上乘势差，不对$a_T\Phi_a$整体作差，以免产生题设未包含的交叉扩散项。相邻含水率极接近时用导数在中点的展开处理消减误差。系数函数对Newton试探点使用正值延拓，但不裁剪求解状态；接受状态另行检查。

中心面两种面量均为0；表面按照当前半径计算：

\[
G^T_{N+1/2}=-hR(T_N-T_\infty),\qquad
G^C_{N+1/2}=-\beta R(C_N-C_{\rm eq}).
\]

正式基线不加入表面潜热项。源码保留的 `surfaceLatentFraction` 是独立压力情景开关，当前三个逐问入口均为0。离散材料导数为

\[
\dot T_i=\frac{G^T_{i+1/2}-G^T_{i-1/2}}{R^2w_i(\rho c_p)_i},\qquad
\dot C_i=\frac{G^C_{i+1/2}-G^C_{i-1/2}}{R^2w_i},\qquad
\dot L=\frac{2\beta}{R}(C_N-C_{\rm eq}).
\]

对水分方程乘$2w_i$并对全部控制体求和，内部共享面量相消，因此

\[
2\sum_iw_iC_i(t)+L(t)=2.55
\]

是程序检查的离散干基质量关系。它是实现自洽性检查，不证明边界平衡假设或材料物性的真实准确性。热侧采用题设给定的有效$\rho c_p$，不能仅由上述瞬时显热方程把整个物理过程的能量变化都视为已经解释。

Q1和Q23半径固定，Q4由附件2进行时间插值，采用固定长度、径向同比收缩及材料骨架无相对迁移的假设。材料坐标形式不另加网格平流项。环境0–4 h由附件1线性插值，之后50°C/0.05平台是明确的延拓假设。

时间求解使用SciPy BDF及解析稀疏Jacobian，在4 h处切段。Q1求至1800 s；Q23/Q4事件函数为全体离散节点的$\max_i C_i-0.15$，方向为向下穿越。连续事件后实际续算到$\lceil t_{\rm event}\rceil+1$秒，保留事件后可查询轨迹。报告时间在0.0001 h格点向上选取，并通过未舍入全域最大含水率严格小于0.15来逐格核验。

`diskDense.py`将每个接受步的原精度BDF多项式写入独立磁盘缓存，仍使用SciPy同一稠密输出公式。工作簿导出直接查询这一live Run；60秒采样NPZ只供审查和数值对照。Q4查询的是实际物理半径，域外位置返回NaN并写为空白，当前真实表面独立输出。

正式细网格是Q1/Q23的N3200和Q4的N6400；N40快速检查仅检验整条执行链路。数值复现容差、输出契约和GUI/人工审查边界见 `README.md`。
