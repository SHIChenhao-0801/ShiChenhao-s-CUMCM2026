# 08 参考文献与检索方法

> **现状**：目前**还没有正式参考文献表**，只有 6 条笔记里的"理论来源"链接。
> 这一页给你三样东西：① 可以**直接核验**的来源（已确认可访问）；② 需要你**自己去核对版次页码**的教材类候选；③ 检索方法与格式模板。
>
> **铁律**：**不存在的文献绝对不能进参考文献**。凡是自己没有亲眼见到出版信息的条目，一律先标"待核"，核不到就删掉。评委查文献造假是很严重的扣分项。

---

## 一、硬规则

1. 参考文献属于**正文**，计入 30 页上限。
2. 校内要求"摘要至参考文献至少 15 页"，所以参考文献页也是页数的一部分，但**不要为了凑页数堆砌无关文献**。
3. **AI 使用声明必须放在参考文献之前**。
4. 正文中每一个引用点都要在文末有对应条目，文末每条都要在正文中被引用过（一一对应）。
5. 数量建议 **8–15 条**：题面与数据 2 条、基础理论 4–6 条、数值方法与工具 3–5 条、应用背景 1–2 条。

## 四、怎么找（给新手的检索流程）

### 第 1 步：先判断"这个论点需要什么级别的来源"

| 论点类型 | 需要的来源 |
|---|---|
| 一条公认的物理定律（Fourier、Fick、Arrhenius） | 教材或权威技术文档 |
| 一个换算关系（含湿量↔分压、干基↔湿基） | 手册（ASHRAE、FAO）或教材 |
| 数值方法（BDF、有限体积） | 数值分析教材或求解器官方文档 |
| 数据与题目条件 | 题面与附件本身 |
| 工艺背景 | 期刊综述论文 |

**不需要引用的**：你自己推导出来的中间步骤、你自己算出来的数值结果。

### 第 2 步：去哪找

| 工具 | 用途 | 入口 |
|---|---|---|
| 校内图书馆 OPAC / 读秀 / 超星 | 查教材的**真实版次、出版社、年份、页码** | 学校图书馆主页 |
| 中国知网 CNKI | 中文期刊与综述 | `https://www.cnki.net` |
| Google Scholar / 百度学术 | 找高被引综述 | `https://scholar.google.com` |
| 官方文档 | 软件与算法的权威说明 | 各软件官网 |
| 官方机构手册 | 物性与湿空气数据 | FAO、ASHRAE |

### 第 3 步：关键词（可直接复制去搜）

- 中文：`圆柱 非稳态导热 有限体积`、`热风干燥 含水率 扩散模型`、`中药材 干燥 动力学`、`变物性 热湿耦合 数值模拟`、`收缩 移动边界 干燥`
- 英文：`cylindrical transient heat conduction finite volume`、`convective drying moisture diffusion model`、`variable properties heat and moisture coupling`、`shrinkage moving boundary drying`

### 第 4 步：筛选标准（按顺序排除）

1. **能查到完整出版信息**（作者、题名、出版社/期刊、年、卷期、页码）→ 保留；查不到 → 丢弃。
2. 来源类型优先级：教材/手册/官方文档 > 期刊论文 > 学位论文 > 网络文章。
3. 网络文章只能用于**背景**，不能用来支撑关键公式或参数。
4. **不要引用 2018 年 A 题的优秀论文原文**（可作为背景提及，但不能整段引用或抄公式）。
5. 每条文献必须在正文里有**确切的引用位置**（引什么，就在那句后面标）。

### 第 5 步：常见坑（务必避开）

- ❌ 从百度文库、道客巴巴、CSDN 博客直接抄文献条目——**版次页码经常是错的**。
- ❌ 用 AI 生成的"看起来很像真的"文献条目——**必须逐条核实**。
- ❌ 引了一本书但从没打开过——如果评委追问内容你答不上来，比不引更糟。
- ❌ 参考文献里的 URL 打不开——交稿前每条链接点一遍。

## 五、格式模板（GB/T 7714 常用格式）

**专著**：
```
[序号] 作者. 书名[M]. 版次. 出版地: 出版社, 出版年: 起页-止页.
```
例：`[1] 杨世铭, 陶文铨. 传热学[M]. 4版. 北京: 高等教育出版社, 2006: 60-85.`

**期刊论文**：
```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起页-止页.
```
例：`[2] 张三, 李四. 中药材热风干燥特性研究[J]. 农业工程学报, 2020, 36(5): 280-288.`

**电子资源 / 技术文档**：
```
[序号] 作者/机构. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```
例：`[3] COMSOL. Heat Transfer Theory[EB/OL]. [2026-09-10]. https://doc.comsol.com/....`

**报告 / 手册**：
```
[序号] 机构. 报告名[R]. 出版地: 出版者, 年.
```

> 全文统一用同一种格式，**序号按正文首次出现顺序排列**（顺序编码制）。
