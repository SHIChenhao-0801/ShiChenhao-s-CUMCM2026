# 01 四问关系与论文骨架

## 一、先把四问的关系说清楚（这段可以直接改写成论文第 2 节）

四问**不是四段依次拼接的时间线**，而是"从简到繁的四层模型"，必须站在同一个统一模型上讲：

```
统一模型：一维径向热湿耦合 PDE（傅里叶导热 + Fick 扩散 + 干基质量守恒）
    │
    ├─ 问题一：把这个模型的"物性"冻结成常数（附录2），只算 0–1800 s 的预热阶段
    │            → 目的是拿一个可以和解折解对照的短时基线
    │
    ├─ 问题二：从 t=0 起，全程换成附录3 的变物性（ρ、cp、k 依赖 C；D 依赖 C 和 T）
    │            → 预热与恒温干燥统一求解，不再分两段
    │
    ├─ 问题三：直接复用问题二那条解，对全域最大含水率施加"< 0.15"阈值事件
    │            → 求出烘干时长（不重新建模，只更换判据）
    │
    └─ 问题四：从 t=0 起换成附录4 物性，并叠加附件2 的半径收缩（移动域）
                 → 再求一次烘干时长
```

**三条必须写进论文的关键关系**：

1. **Q2 和 Q3 是同一个解**。Q3 不是新模型，是在 Q2 的解上找"全域最大含水率首次严格低于 0.15"的时刻。
2. **Q1 不能接到 Q2**。Q1 只算 1800 s，Q2 必须从 t=0 重新开始，**不能把问题一的末状态当作问题二的初值**。
3. **Q4 与 Q3 的时长差不能全归因于收缩**。Q4 同时换了两样东西：物性（附录3→附录4）和几何（固定半径→收缩）。若要单独说明收缩的作用，必须做"同附录4物性、固定半径 vs 收缩"的对照——我们做了，结果见 `04_问题三四_写作页.md`。

## 三、7 条模型假设（第 4 节直接照此展开）

每条按"**假设内容 → 为什么这么假设（依据）→ 什么情况下会失效（影响）→ 我们怎么检查（检验）**"写四句话。这套写法能直接反映建模水平，评分点明确提到"假设有依据"。

| 编号 | 假设 | 依据 | 影响与边界 | 我们的检验/披露 |
|---|---|---|---|---|
| A01 | 轴对称、一维径向，忽略端面与轴向变化；固定长度 L=0.25 m | 题目按"到药材中心的距离"给结果；长径比 L/(2R₀)=6.25 | 题目是有限圆柱，**不等于端面绝热**；端面积/侧面积 = R₀/L = 0.08，不足以单独证明影响可忽略 | 已做量级分析与二维轴对称对照讨论；在论文中明确写为近似 |
| A02 | 用有效显热容量闭合热方程：`B(C)∂T/∂t = div(k∇T)`，B = ρ_eff·c_p | 题目给了 ρ、c_p、k 和对流换热参数，未给完整的相变/焓闭合 | 基线**不显式包含相变潜热**，也**忽略了水分迁移携带的焓**。潜热/显热参考比约 21.6，**不能用"潜热很小"来论证** | 已给出潜热量级核算；已做"表面潜热"压力测试情景并说明其未闭合 |
| A03 | C 为干基含水率（kg 水/kg 干物质）；干物质骨架守恒，水通量用有效 Fick 本构 | 题目明确"干基含水率"；干物质质量守恒 + 给定半径可相容闭合 | ρ_d0 只决定总水质量的单位尺度，**不影响**空间均匀骨架下的 C 解 | 已做质量恒等式检验（残差 ~1e-14） |
| A04 | 材料表面的平衡含水率取烘房给出的水分值：`-D·∂C/∂r = β(C_s - C_eq)` | 题目给了环境 kg/kg 与有效传质系数 β，未给吸附等温线 | 空气的 kg/kg（每 kg 干空气）与药材的 kg/kg（每 kg 干物质）**分母不同**，这是简化约定，**不是**由单位相同推出的物理等价 | 已做 Ceq 比例/偏移的敏感性讨论；明确声明缺少等温线 |
| A05 | 0–4 h 按附件1 分段线性插值；4 h 之后基准取 50 °C 与 Ceq=0.05 | 附件末段接近恒温恒湿平台，题目称"恒温干燥" | 50/0.05 **只是候选工况**，不是其后 68 h 的实测值 | 已比较"末值保持""末 1 h 均值保持""平台温湿扰动"三种情景 |
| A06 | Q4 采用同比径向材料收缩：`u(r,t)=r·R'(t)/R(t)`，长度不变 | 与表面速度、空间均匀干物质骨架守恒相容的**最简**闭合 | 附件**没有**内部位移或长度轨迹，不能证明真实内部收缩均匀 | 已做同物性固定/收缩对照；明确禁止重复加入 ALE 平流项或体积稀释项 |
| A07 | Q2–Q4 沿用 h = 25 W/(m²·K)、β = 8×10⁻⁷ m/s | 同一药材、同一烘房，题目只明确更换给出的经验物性 | 风速或温湿变化可能改变这两个系数，当前无实测 | 已做 h、β 各 ±10%/±20% 的参数情景，**报告为设置差异而非实测误差** |

## 四、符号说明表（第 4 节末尾直接用）

| 符号 | 含义 | 单位 | 说明 |
|---|---|---|---|
| t | 时间 | s | 论文显示用 h 时须除以 3600 |
| r | 到药材中心的径向距离 | m | 输入是 cm，须乘 0.01 |
| x = r/R(t) | 材料归一化径向坐标 | 1 | x=1 永远是真实表面；固定 x 与固定 cm 不同 |
| T | 药材温度 | K | 初值 301.15 K；摄氏显示为 T−273.15 |
| C | 干基含水率 = m_水/m_干物质 | kg/kg | 初值 2.55；允许 >1 |
| w = C/(1+C) | 湿基质量分数 | 1 | **仅**用于题给 c_p、k 经验式 |
| R(t) | 药材当前半径 | m | R₀ = 0.02 m；Q4 由附件2 插值 |
| ρ_eff | 有效密度（用于热容量） | kg/m³ | Q1 820；Q23 650+128C；Q4 760+90C |
| ρ_d | 守恒干物质密度 | kg/m³ | Q1 230.986；Q23 275.042；Q4 278.7324（初始标定） |
| c_p | 比热容 | J/(kg·K) | 题给经验式 |
| k | 导热系数 | W/(m·K) | 题给经验式 |
| D | 有效水分扩散系数 | m²/s | 题给经验式，依赖 C（和 T） |
| h | 对流换热系数 | W/(m²·K) | 25 |
| β | 对流传质系数 | m/s | 8×10⁻⁷ |
| B = ρ_eff·c_p | 有效体积显热容量 | J/(m³·K) | 随 C 变化 |
| q_r | 径向导热热流密度（**向外为正**） | W/m² | q_r = −k ∂T/∂r |
| j_w | 径向水分质量通量（**向外为正**） | kg/(m²·s) | j_w = −ρ_d D ∂C/∂r |
| ℓ(t) | 每单位初始干物质的累计失水 | kg/kg | 初始为 0 |
| C_eq | 环境对应的等效平衡含水率 | kg/kg | 来自附件1（等效闭合） |
| T∞ | 烘房温度 | K | 附件1 |
| t\* | 全域达标时刻 | s | 论文按 h 报告 |

> **提醒**：ρ_eff 与 ρ_d 是**两个不同的量**，全文必须分开写，不能混用。这是本题最容易出错的概念之一。
