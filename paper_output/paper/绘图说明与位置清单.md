## 图1：问题一指定时刻的径向温度与含水率

**绘制内容。** 左右双面板，分别给出温度与干基含水率随物理半径的曲线。七个时刻严格取 100、300、600、900、1200、1500、1800 s。两面板使用同一套时刻颜色和次序，图例写明秒；标明中心与表面，展示表面先响应、中心水分响应较慢。

**坐标与单位。** 两图横轴均为距中心距离 r / cm，范围 0–2；左图纵轴为温度 T / °C，右图为干基含水率 C / (kg水/kg干物质)。图中可简写 kg/kg，但图注须说明干基。不得把湿基质量分数与干基比值混用。

**实际数据与取数。** 首选 `paper_output/results/production/final_v6a/figures/fig_q1_profiles_data.npz`：`times_s` 长度7，`radii_m` 长度121，`temperature_C` 与 `C` 均为 7×121，行对应时刻、列对应半径；横轴为 `radii_m×100`，温度已为摄氏度，不再减273.15。正文表格可用 `outputs/q1_paper_temperature.csv`、`outputs/q1_paper_moisture.csv` 核对；这两个 CSV 只有5个指定半径且已四位舍入，不用于代替121点曲线。上述 `outputs/` 位于同一正式结果目录。

**关键假设标识。** 图注注明“问题一、附录2物性、固定半径2 cm、生产 N3200 数值结果”。曲线上的点为模型结果，不画成实验观测。初始 C=2.55 kg/kg；中心曲线显示2.5500不代表全过程完全未变化。

## 图2：烘房边界观测、插值与长期平台

**绘制内容。** 两行面板：上行为环境温度，下行为环境水分指标。0–4 h 画原始点和连接相邻点的分段直线；另设长时间轴面板或插图展示4 h之后至约60 h的50°C、0.05平台。用竖线或背景分区标明4 h观测终点，实测点与假设平台采用不同标记。

**坐标与单位。** 横轴 t / h；上图 T∞ / °C；下图“环境水分指标 Y / (kg/kg)”。CSV 字段为 `air_moisture_kg_per_kg`，不标成相对湿度百分比，也不直接标成药材实际含水率。模型把该指标作为边界平衡含水率的解释，应在图注说明。

**实际数据与取数。** `paper_output/data_cleaned/A_environment_observed.csv` 共241行，列为 `time_s、time_h、temperature_C、temperature_K、air_moisture_kg_per_kg`，间隔60 s，覆盖0–14400 s。取 `time_h`、`temperature_C` 和环境水分列即可。边界处理可定位 `paper_output/code/modeling/drying_core.py` 第87–106行；正式 `Q23/summary.json` 的 `settings.boundary_extension=nominal`、`tail_temperature_C=50.0`、`tail_equilibrium=0.05` 提供设置记录。

**关键假设标识。** 4 h后的平台是“假设延拓”，不是新观测，也不是末次值保持。实际 t=4 h 的末点为50.165°C和0.04986，生产实现仅在 t>4 h 切换到50°C和0.05。保留这一小跳变或用开闭端点注明，不改末点、不平滑为虚构连续曲线。图注可写：“0–4 h为题给观测及线性插值；4 h后采用规定工况平台，属于条件预测边界。”

## 图3：问题二中心与表面的热湿响应

**绘制内容。** 两个时间面板，各画中心和表面两条曲线。温度面板展示0–4 h；含水率面板展示0至临界达标附近。中心和表面在两面板使用相同颜色或线型，不强制两面板共用时间范围，以免压缩早期热响应。

**坐标与单位。** 横轴均为 t / h，但范围分别为0–4 h及0–约57.47 h；纵轴分别为 T / °C、干基 C / (kg/kg)。中心 r=0，表面 r=2 cm。

**实际数据与取数。** `paper_output/results/production/final_v6a/Q23/sampled_solution.npz`：`times_s` 共3452个，`material_x` 为21个点且首尾为0和1；`T_K`、`C` 均为3452×21。取首列中心、末列表面，`times_s/3600` 转为小时，`T_K−273.15` 转为摄氏度。筛取前4 h温度；含水率取至事件时刻。正文指定时刻可用同目录 `outputs/q2_paper_temperature.csv`、`outputs/q2_paper_moisture.csv` 核对，它们不是全过程时程。事件及严格报告点见 `Q23/summary.json` 的 `completion`。

**关键假设标识。** 图注明“问题二、附录3整组变物性、固定半径、N3200、4 h后名义平台”；问题二从原始均匀初始场独立开始，不与问题一1800 s状态拼接。含水率后半段是延拓工况下的条件预测；温度接近环境不等于中心含水率已达标。

## 图4：问题三全域阈值与临界根附近放大

**绘制内容。** 主图画中心、表面和全域最大含水率，再画 C=0.15 kg/kg 水平阈值线。主轴可按正文要求设0–60 h，但真实曲线只到已计算的终点206902 s，即约57.47278 h，之后留空。另设临界根附近的局部放大窗，用两种点形标记临界根 t_c 与严格报告时刻 t_r。中心与最大值后期重合，应直接重合并用图例说明，不能人为纵向错开。

**坐标与单位。** 主图 t / h 与 C / (kg/kg)。局部窗推荐横轴为相对临界根的秒差 t−t_c / s，纵轴为 C_max−0.15 / (kg/kg)，便于分辨约0.353 s的 t_c、t_r 间隔；这是显示坐标变换，不修改浓度或时间。

**实际数据与取数。** 全程首选 `paper_output/results/production/final_v6a/figures/fig_q3_drying_data.npz`，使用 `times_s、centre_C、surface_C、max_C`，共266个真实采样时刻。`max_C` 是生产全体离散节点的最大值，生成依据在 `paper_output/code/modeling/publication_plots.py` 第184–186行；不得以21个稀疏径向采样点的最大值替代。局部可取 `Q23/sampled_solution.npz` 最后若干时刻，并明确只是已存样点的连线；`Q23/summary.json` 提供根和报告点：

| 标记 | 时间/h | 时间/s | 全域最大干基含水率 |
|---|---:|---:|---:|
| t_c | 57.47230195056044 | 206900.28702201758 | 0.15 |
| t_r | 57.4724 | 206900.64 | 0.14999989718225315 |

`t_r` 不在该采样 NPZ 中，应从 JSON 的 `completion.reported_time_s`、`max_C_at_reported_time` 读取并作为明确点标出；不能从四位表格0.1500推断严格性。曲线末端206902 s是额外验证终点，不是 t_r。图中若画 t_c 到 t_r 的线段，只能标为已知点间的显示连线，不能宣称新生成稠密数值轨迹。

**关键假设标识。** “全域最大值低于0.15”为严格报告条件；t_c 是等号根，t_r 才是上取并检查后的严格报告。图注注明 N3200 与长期边界假设；该图不表示物理置信区间。
