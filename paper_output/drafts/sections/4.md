# 4 符号说明

| 符号 | 说明 | 单位 |
| --- | --- | --- |
| t | 时间 | s |
| r | 到药材中心的径向距离 | m |
| x=r/R(t) | 材料归一化径向坐标 | 1 |
| T | 药材温度 | K |
| C | 干基含水率=m水/m干物质 | kg/kg |
| w=C/(1+C) | 湿基质量分数 | 1 |
| R(t) | 药材当前半径 | m |
| ρeff | 有效密度（用于热容量） | kg/m³ |
| ρd | 守恒干物质密度 | kg/m³ |
| cp | 比热容 | J/(kg·K) |
| k | 导热系数 | W/(m·K) |
| D | 有效水分扩散系数 | m²/s |
| h | 对流换热系数 | W/(m²·K) |
| β | 对流传质系数 | m/s |
| B=ρeff·cp | 有效体积显热容量 | J/(m³·K) |
| qr | 径向导热热流密度（向外为正） | W/m² |
| jw | 径向水分质量通量（向外为正） | kg/(m²·s) |
| ℓ(t) | 每单位初始干物质的累计失水 | kg/kg |
| Ceq | 环境对应的等效平衡含水率 | kg/kg |
| T∞ | 烘房温度 | K |
| t* | 全域达标时刻 | s |
