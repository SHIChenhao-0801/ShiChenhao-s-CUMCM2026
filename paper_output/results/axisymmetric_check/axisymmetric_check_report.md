## 1. 物理和离散口径

- 完整圆柱R=0.02m、L=0.25m，利用轴对称和中面对称计算r∈[0,R]、z∈[0,L/2]；z=0为长度中点。
- Q2/Q3附录3物性，环境数据和4h后50°C/0.05延拓直接调用同一RadialModel；无潜热、无收缩。题给ρ仍作为有效热容量密度，干基水另守恒。
- r=0与z=0无通量；r=R始终施h=25、β=8e−7。端面开启时z=L/2施相同h/β，关闭时hz=βz=0，轴向扩散项始终保留。
- 含中心/表面的节点对偶有限体积，径向、轴向使用相同Kirchhoff浓度势及面温均值；导热面k调和。两维均共享内部面通量，累计侧面及端面失水随BDF一起积分。
- 具体方程、符号、自变量/因变量、几何权重和质量推导见notes/A-modeling/2026-09-10/physics/axisymmetric_derivations.md。

开启端面的两组最慢点都由全网格最大值检查确定为r=0、z=0。关闭端面后所有轴向位置在理论上等价，最大位置受约3.47e−10的浓度数值散差影响而退化，不能解释其输出的某个z为特殊物理最慢点。

这里求解器停止于max C=0.15的临界等号，报告它是严格干燥条件可行集合的下确界；本对照没有在临界后追加“已严格低于”的时间步。正式输出需要主流程继续做穿越后验证。

## 3. 平均和中心场差异

保存时刻包括0、0.5h、3h、每6h及两解共同终止时刻。以下“最大差”只针对保存的采样时刻，不是对所有连续时间的误差上界。

60×60开启端面：

- 最大采样平均浓度差为0.0551822187kg/kg，出现在已存3h时刻：二维平均1.3272736132，一维平均1.3824558318。
- 6h平均：二维0.7343075137，一维0.7816692471；12h平均：二维0.3173499452，一维0.3367001624。
- 二维临界时刻，二维平均0.1209876783，一维在同一时刻平均0.1240871507，差−0.0030994724kg/kg。
- 中截面径向浓度场最大采样差约2.4156e−5kg/kg，中截面温度最大采样差约0.0013051K。
- 全部接受时间点的最大轴向浓度跨度约0.97627kg/kg，说明某些早期端部区域与中部具有很明显的不同。不能把最终事件差小改写成“端面处处可忽略”。

端面增大失水面积，靠近两端区域提前变干，因而全柱平均明显下降；最终判据受远离两端的中截面圆心控制，传到该位置的轴向影响较弱。此解释与实际求出的最慢位置和场差一致，不依赖预先假设中心必最慢。

## 4. 回归和质量验证

关闭端面的30×30二维连续问题应退化为一维。实际临界时刻差约0.00565秒，最大采样中截面浓度差1.7724e−6kg/kg、温度差2.2118e−4K。二者相同容差的独立自适应BDF使用不同时间点和RMS误差权重，故不能要求每个输出逐位相同。

另以同一个非均匀径向温/湿状态沿z复制，直接比较**相同状态的右端算子**，结果为：

| 检查量 | 最大绝对差 |
|---|---:|
| 二维关闭端面与一维的温度时间导数 | 3.4694e−18K/s |
| 水分时间导数 | 3.1171e−19(kg/kg)/s |
| 累计失水时间导数 | 6.7763e−21(kg/kg)/s |
| 同状态瞬时质量残差 | 9.4868e−20(kg/kg)/s |

该检查证明两个程序采用一致的空间方程/通量口径，回归剩余差来自数值时间轨迹等因素，而不是漏掉半径/半长系数。质量平均权重为2wrwz，侧面失水系数2β/R，镜像两个端面对应β/H=2β/L；所有全程质量残差都小于4.27e−14。

没有负含水率；三次计算最小C分别约0.0526373、0.050000572、0.050000659kg/kg，初始最大C=2.55。BDF均成功结束。质量/正性通过不能替代网格、时间或真实实验验证。
