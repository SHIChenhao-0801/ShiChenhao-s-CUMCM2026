## 建议图注

1. 固定半径 2 cm、题目附录2物性条件下，七个指定时刻的径向温度和干基含水率分布（N = 3200）。两个面板中同一颜色和线型表示同一时刻。

2. 烘房环境观测及平台延拓。0–4 h 使用观测数据和分段线性插值；4 h 后将环境温度和空气水分指标分别延拓为 50 °C 和 0.05 kg/kg。虚线及浅灰区域表示假设平台，左端空心点表示右侧极限，不能与 4 h 的原始观测值混同。

3. 题目附录3物性、固定半径条件下的中心与表面热湿响应（N = 3200）。温度面板展示前 4 h，含水率面板展示同一数值轨迹从初值至临界达标的全过程。含水率均为干基值。

4. 全域含水率达标过程与临界附近的阈值差。主图使用对数纵轴；中心含水率与全域最大含水率在保存时刻重合，按实际位置叠加绘制。局部图仅连接已有的两个全域最大值保存点，三角形为独立核验时刻 t_r 的全域最大值，未添加新的预测点。临界根 t_c 与严格达标取值 t_r 相差约 0.352978 s。

5. 题目附录4物性、径向同比收缩且轴向长度固定条件下的半径变化及域内干基含水率（N = 6400）。各条剖面在相应时刻的真实表面终止，点形标记表示表面位置；右图使用对数纵轴。问题三与问题四的对比同时包含物性和几何变化，不能将两者时差全部归因于纯收缩效应。

6. 统一 N = 800 和零潜热负荷下的经验边界阻力情景比较。两条线分别为题目附录3物性、固定半径模型及题目附录4物性、径向收缩模型；标记仅对应 p = 1、2、4 的已计算临界时长。该经验参数族未经药材实测等温线标定，连线仅辅助阅读。

## 复现与数据来源

在正式工作区根目录执行：

```powershell
& 'D:/R-4.6.1/bin/Rscript.exe' --vanilla 'paper_output/figures/review_20260913/draw_figures.R'
```

绘图全部由 R 4.6.1 自带的 graphics/grDevices 实际执行，无需安装额外 R 包。中文使用 Microsoft YaHei，数学轴标签使用 Times New Roman 斜体变量；PNG、PDF、SVG 均通过 Cairo 图形设备输出。运行日志 `R_run.log`、环境 `R_session_info.txt`、轴范围检查 `axis_range_checks.csv`、关键数值检查 `plot_checks.csv` 均保留。

`input_data/CSV/` 是 `paper_output/handoff/six_figures_20260912/CSV/` 的逐字节副本，共 14 表、4627 行。输入哈希及副本一致性见 `input_sha256.csv`；原始 NPZ/JSON 与正文表的映射见同级复制的 `source_manifest.json`。图1/3/4为 N = 3200，图5为 N = 6400，图6均为 N = 800。

R 启动时受到父进程 `C.UTF-8` locale 影响出现四条 locale 提示，脚本随后显式设置 Windows 可用的 `Chinese_China.utf8`，中文文件读取、中文渲染及全部绘图成功，未安装或更改系统环境。
