### 1.2 由傅里叶导热定理与水分扩散定理得到的微分方程

**傅里叶导热定律**（向外为正）：
```
q_r = -k ∂T/∂r                    [W/m²]
```
取半径 r、厚 dr 的圆柱薄壳，令 dV=2πrLdr、A(r)=2πrL，则"积累 = 净流入"给出
```
ρ_eff c_p ∂T/∂t = (1/r) ∂r( r k ∂T/∂r )        …… Q1–Q3（固定半径）
```
程序里统一记 `B(C) = ρ_eff · c_p`，即
```
B(C) ∂T/∂t = (1/r) ∂r( r k(C) ∂T/∂r )
```

**水分扩散（有效 Fick 本构，干基）**：
```
j_w = -ρ_d D ∂C/∂r                [kg/(m²·s)]
```
干物质守恒与水质量守恒相减（`notes/A-principles/…md` §4）：
```
ρ_d (∂C/∂t + u ∂C/∂r) = (1/r) ∂r( r ρ_d D ∂C/∂r )
```
只有 `ρ_d` 在空间上均匀时才能从散度内约掉，前三问 `u = 0`，于是
```
∂C/∂t = (1/r) ∂r( r D(C,T) ∂C/∂r )
```

**Q4 材料坐标换元** `x = r/R(t)`（`f_t|_r = F_t|_x - (xR'/R)F_x`，`f_r = F_x/R`），配同比径向材料速度 `u = xR'`，相对平流项恰好抵消，四问统一为
```
B(C) ∂T/∂t = (1/(R(t)²x)) ∂x( x k(C) ∂x T )
    ∂C/∂t = (1/(R(t)²x)) ∂x( x D(C,T) ∂x C )
```
Q1–Q3 取 `R(t) ≡ R₀ = 0.02 m`；Q4 的 `R(t)` 由附件 2 线性插值，程序只直接使用 R，不对折线求数值导数。

2018 年 A 题是 **《高温作业专用服装设计》**：

- 服装分三层织物 I/II/III，III 层与皮肤之间是空气层 IV；假人体内温度 37 °C。
- 问 1：环境 75 °C、II 层厚 6 mm、IV 层厚 5 mm、工作 90 min，用附件 1 的物性建温度分布模型，输出 `problem1.xlsx`。

- 问 3：环境 80 °C，同时优化 II、IV 层厚度，工作 30 min，约束同上。

**可以借鉴的（方法层面）**

1. 建模链条写法：守恒/导热方程 → 层间界面连续条件 → 环境侧与人体侧边界 → 差分离散 → 数值求解 → 验证。这套骨架与本次 A 题完全同构。
2. 离散化与验证的呈现方式：显式/Crank–Nicolson 对比、空间步长与时间步长加密、稳定性与网格无关性。

## 3. 物理定律是否真实、公式是否严格推导、出处与参考文献

### 3.1 属于真实物理定律、并且推导正确的部分

- **傅里叶导热定律** `q=-k∇T`：真实、标准。
- **有效 Fick 本构** `j_w=-ρ_d D∇C`：干基形式的扩散通量，真实、标准。
- **干物质与水质量守恒**：真实守恒律；两式相减得到 `ρ_d(C_t+uC_r)=(1/r)∂r(rρ_dDC_r)`，推导正确。
- **圆柱薄壳几何** `dV=2πrLdr`、`A(r)=2πrL`：正确，`1/r` 来自传递面积随半径变化。
- **Kirchhoff 变换** `F(C)=Ce^{−a/C}+aEi(−a/C)`，`F'(C)=e^{−a/C}`：代数核验通过。
- **移动域链式法则**与 `R⁻²`、`hR`、`βR` 的正确出现：核验通过，无漏项也无重复平流项。

### 3.2 不是"定律"、必须写成"模型选择/假设"的部分（论文里不能含糊）

1. **热方程的有效显热闭合**。完整组分显焓守恒是
   `ρ_d(c_d+C c_w)D_tT = ∇·(k∇T) − c_w j_w·∇T`，
   主模型**忽略了右端携焓梯度项**，并把左端容量换成题给 `ρ_eff c_p`。在 C=0.15 参考状态，`B_eff` 与组分容量之比约 **2.11572**，即这不是"小修正"。**结论：真实定律 + 明确的额外闭合步骤，不是从第一性原理严格推出。**
2. **气固边界 `C_eq`**。附件 1 的 kg/kg 是**空气干基**含湿量，材料的 C 是**药材干基**含水率，分母不同。直接把附件数值当作材料平衡含水率是**等效闭合约定**，不是实测气固平衡；严格化还需要吸附/解吸等温线与水活度（题目未给）。
3. **不显式计潜热**。以 L_v≈2.38–2.4 MJ/kg 估算，除水潜热与显热参考比约 **21.6 倍**，所以**不能**用"潜热很小所以忽略"来论证。基线不含潜热是选择，不是结论。
4. **Q4 收缩闭合**。附件只给 `R(t)`，内部运动取 `u=rR'/R`（同比收缩）+ 长度不变 + 均匀干骨架，这是最简相容闭合，无实测内部位移支撑。另外：题给 `ρ=760+90C` 若解释为真实湿密度，与"给定半径 + 固定长度 + 严格干质量守恒"**不能同时精确成立**（必要条件 `R(t) ≥ 1.21120 cm`；72 h 时即使全干也只能容纳初始干质量的 97.83 %）。主模型的选择是"题给 ρ 只用于有效热容量，ρ_d 另行守恒"。
5. **9 条经验式**（附录 2–4）是题给拟合关系，**没有原始拟合样本**，不能声称由守恒定律推导，也不能虚构拟合精度。

## 6. 涉及梯度的公式正负号是否清楚

### 6.1 定义层面：清楚且一致

- 傅里叶：`q_r = -k ∂T/∂r`，**向外为正**；负号保证热从高温流向低温。
- Fick：`j_w = -ρ_d D ∂C/∂r`，**向外为正**；`C_s > C_eq` 时 `∂C/∂r < 0` → `j_w > 0` → 水向外。
- 热流方向自检：加热时 `T∞ > T_s` → `q_r < 0` → 热流入药材 ✓

### 6.2 代码层面：用了明确的"正梯度通量记号 G"，并解释了与物理通量的关系

```python
heatG[1:-1]  = x面/dx * harmonic(k) * diff(T)      # G^T，单位 W/m
waterG[1:-1] = Kirchhoff形式
waterG[-1]   = -beta * R * (C[-1] - ceq)
heatG[-1]    = -h    * R * (T[-1] - tair)
derivative[:-1:2] = diff(heatG) / (R**2 * w * rho * cp)
derivative[1:-1:2] = diff(waterG) / (R**2 * w)
```
- `G` 是"正梯度"记号，**真实向外扩散通量带负号**；组装成 `(G_{i+1/2} − G_{i-1/2})` 后与薄壳守恒
  `V(ρc_p)Ṫ = A_{i-1/2}q_{i-1/2} − A_{i+1/2}q_{i+1/2}`（q 向外为正）完全一致。
- 表面 `G^T_{N+1/2} = −hR(T_N−T∞)`：加热时 `T∞>T_N` → `G>0` → `Ṫ>0`（吸热）✓
- 中心与最外侧内界面：`G=0`（面积为 0），不出现 `1/r` 奇点 ✓
- `rhs` 与公式说明 §6 都留了明确注释："实际向外扩散通量带负号"、"中心面面积为零"。

### 6.3 已被显式指出、论文里必须保留的三个符号陷阱

1. **不能对 `exp(−3850/T)·F(C)` 整体作差**（会凭空引入温度梯度驱动的交叉扩散/Soret 项）。代码**只对 F(C) 作差**，温度因子取面平均 `T̄=(T_i+T_{i+1})/2`。
2. **不能把 `B(C) ∂T/∂t` 写成 `∂t(B(C)T)`**（会多出一个未配套平衡的源项）。
3. **系数正性延续只作用于"算系数时"的 `max(C,1e-12)`，不对已接受状态裁剪**；该分支在阈值处不可微，所以局部 Jacobian 检验不能宣称在任意非物理状态形式化成立。

### 6.4 一处建议（论文可读性）

论文里统一声明"**向外为正**"，并在 Robin 条件处注明 `r=R` 的外法向为 `+r`；符号表里严格区分 `ρ_eff`（有效热容密度）与 `ρ_d`（守恒干物质密度）——报告里这两个符号都出现，本科生极易混。

## 7. 初值/边值条件是否明确、边界类型有无误用

### 7.1 初值与边界（程序与文档完全一致）

```
初值：   T(x,0) = 301.15 K        C(x,0) = 2.55        （空间均匀，属建模解释）
中心：   ∂T/∂x(0,t) = 0           ∂C/∂x(0,t) = 0       （轴对称/零通量）
表面：   −(k/R) ∂T/∂x(1,t) = h [T_s − T∞(t)]，  h = 25 W/(m²·K)
         −(D/R) ∂C/∂x(1,t) = β [C_s − C_eq(t)]， β = 8×10⁻⁷ m/s
```

### 7.2 边界类型没有误用——理由是网格类型匹配

- 本方案用**含 x=1 表面节点的节点式（vertex-centered）对偶网格**，`T_s`、`C_s` **本身就是 ODE 未知量**，Robin 条件直接给出最外侧面的通量，**程序不需要每步对表面温度/含水率另行求根**。
- 文档明确写了反面情形：**如果改用单元中心网格、最外未知量位于表面以内，就必须处理"半单元内阻 + 气膜阻串联"的等效边界**，而且**不能把这两套修正再叠加到当前节点网格上**（`公式与算法说明.md` §5）。这正是最容易犯的"边界类型误用"，代码避开了。
- 中心：内界面半径 = 0 → 权重 `w₀=(Δx/2)²/2`，面积为 0，不做 `1/x` 除法 ✓
- 表面通量的单位与量纲自检通过：`G^C` 单位 m²·(kg/kg)/s，除 `R²w` 得 kg/kg/s ✓

### 7.3 三项"不是题给、必须显式声明"的边界相关约定

1. **4 h 后的平台延拓**：`t>14400 s` 取 `T∞ = 50 °C`、`C_eq = 0.05`。这是假设，不是实测。
2. **`C_eq` 的等效映射**：附件 1 的空气 kg/kg 直接当作材料等效平衡含水率。分母基准不同，属题设简化下的等效闭合。
3. **h、β 的延用**：附录 3/4 未重给边界系数，Q2–Q4 沿用 25 W/(m²·K) 与 8×10⁻⁷ m/s；Q4 的 `R(t)` 线性插值、只直接用 R 不数值求导，超出 72 h 才延续末值（**本次 Q4 未触发**）。

### 7.4 Q4 输出域的边界规则（对应题面"药材表面"列）

- `x=1` 永远是真实表面，单独成列；固定物理半径列在 `r_j > R(t)` 时**留空**（域外 ≠ 0 含水率）。
- 实测：`result4.xlsx` 中域外留空 **15,648** 格（`figure_index.json` 的 `masked_outside_count`）。Q4 结束 `R=1.2 cm`，故 1.5/2.0 cm 列全程为空。
