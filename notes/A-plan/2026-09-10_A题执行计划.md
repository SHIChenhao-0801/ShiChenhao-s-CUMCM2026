## 3. 需要认真解决的模型约定

1. 空气水分与药材干基含水率：单位同为kg/kg不保证质量基准相同。等效平衡含水率边界可作为明确的题设简化候选；缺少吸附等温线时不能声称真实关系已经标定。
2. 热湿耦合与潜热：先形成有效显热基线；在物理通量和参数来源能闭合时，检验蒸发耗热对结论的影响。不能通过任意自由参数拟合不存在的内部实测曲线。
3. 一维近似：先做径向模型并说明端面近似。两端面积/侧面积8%是几何比值，不是模型误差8%。二维对照只在基础四问完成且有必要时增加。
4. 长时边界：附件1只到4 h，约50°C、0.05 kg/kg的后续环境是待验证延拓；比较末段均值、末值等合理方案。附件2只到72 h，若仍未达标需明确半径后续假设。
5. 收缩与干物质守恒：内部材料速度不能仅由边界半径唯一确定；同比收缩假设应与材料坐标相容，避免重复网格平流或将干基比值当作体积浓度加压缩项。经验密度作为总表观密度或有效热物性系数的解释必须始终一致。先完成代数相容性检查再写严格守恒结论。

第四问必须比较“附录4＋固定半径”与“附录4＋变化半径”。第三问与第四问同时改变物性，时长差不能全部解释为收缩作用，也不能提前保证第四问更快。

主工具应在今晚模型约定中锁定。当前技能契约原生采用 Python 入口，现有 Python 3.14.7 已能定位 numpy/scipy/pandas/matplotlib/openpyxl 包；这不是导入、求解或 VS 复现验证。建议优先评估 Python＋Visual Studio 以直接对接运行证据；如果团队更能审查 MATLAB，就将 MATLAB 作为核心求解并在本届目录保留真实调用/输入输出契约，不能用空的 Python 文件伪装满足门禁。不要同时维护两套未经验证的完整模型。MATLAB 可在有必要时做少量独立交叉核验。

建议候选离散为圆柱径向有限体积＋隐式/刚性时间积分。先用较粗两档网格定位错误，冻结前补第三档及更严时间容差，按误差决定是否继续细化。节点数与误差目标须先记录，不能仅凭曲线光滑判定正确。没有内部实测曲线时报告数值验证、合理性和敏感性，不能虚构预测准确率或实测RMSE。
