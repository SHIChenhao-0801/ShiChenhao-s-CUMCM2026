**整道题的实际场景。**

小区需要用电，光伏能提供一部分，电池可以把某时段的电留到以后使用，不足部分向外部电网购买。要决定每个时段买多少电、充多少电、放多少电，使供电满足负载并尽量降低费用。

| 2 | 负载与光伏变化；零点先制定计划；不足部分5倍电价紧急购买 | 预测、不对称误差成本、因果回测 |
| 3 | 每6小时有新光伏预报；允许付费调整计划 | 滚动优化、调整费用、预报价值 |

**先统一功率、能量和时间。**

功率单位为kW，表示电能流动的速度；电量单位为kWh，表示一段时间积累的能量。10分钟为

\[
\Delta t=\frac{10}{60}=\frac16\text{小时}.
\]

若一个时段的平均负载功率为 \(L_t\)，则用电量为

\[
\ell_t=L_t\Delta t.
\]

光伏平均功率为 \(V_t\)，发电量为 \(s_t=V_t\Delta t\)。例如3000 kW持续10分钟需要500 kWh，而不是3000 kWh。

若附件数值是时刻瞬时功率，则严格电量应由积分得到：

\[
\ell_t=\int_{t}^{t+\Delta t}L(\tau)\,d\tau
\approx\frac{L(t)+L(t+\Delta t)}2\Delta t.
\]

区间平均值乘时长与瞬时端点梯形积分是不同口径，需根据附件及正式审题决定。下文统一使用已正确转换的“每个10分钟区间电量”。

通常一个自然日对应144个区间、145个储能边界状态：

\[
t=0,\ldots,143,\qquad E_0,\ldots,E_{144}.
\]

但原始结果模板存在时间标签疑点：附件1、2、4给出0:10至0:00+1共144个时刻；结果模板从0:10—0:20开始，且最后一项跨到次日0:10。不能直接把第一个数当成0:00—0:10的值后静默填进0:10—0:20。需保留原模板，明确原始时刻、计算区间和输出标签的映射，必要时查官方澄清。

**储能状态方程从能量守恒得出。**

以下变量均以一个时段为单位：

| 符号 | 含义 | 单位 |
|---|---|---|
| \(q_t\) | 计划向外网购入的电量 | kWh |
| \(c_t\) | 从小区母线输入电池的充电量 | kWh |
| \(d_t\) | 电池输出到小区母线的放电量 | kWh |
| \(E_t\) | 时段开始时电池内部存储的电量 | kWh |
| \(\ell_t,s_t\) | 小区用电量、光伏发电量 | kWh |
| \(p_t\) | 对应结算电价 | 元/kWh |
| \(w_t\) | 未利用的富余能量，不计售电收入 | kWh |

设充电效率 \(\eta_c\)、放电效率 \(\eta_d\)，则

\[
\boxed{
E_{t+1}=E_t+\eta_c c_t-\frac{d_t}{\eta_d}.
}
\]

充入 \(c_t\) 时只有 \(\eta_c c_t\) 留在电池内；要向负载提供 \(d_t\)，必须从内部取出 \(d_t/\eta_d\)。因此效率在充电端相乘，在放电端相除。

附录写“充放电效率为90%”，没有进一步明确单程和往返口径。本教学暂取

\[
\eta_c=\eta_d=0.9,
\]

则充入100 kWh，内部增加90 kWh，再放出只能向负载提供81 kWh，往返效率为81%。若90%被解释为往返效率，可另取对称单程 \(\eta_c=\eta_d=\sqrt{0.9}\)。正式模型需声明采用哪种口径，并检查替代口径的影响。

题设储能参数：

\[
E_{\rm rated}=12000,\quad
1200\le E_t\le10800,\quad
E_{\text{2025-01-01 00:00}}=6000.
\]

最大充放电功率均为5000 kW，因此每个10分钟区间母线侧充放电量上限为

\[
\bar c=\bar d=5000/6\approx833.33\text{kWh}.
\]

最大功率的端口定义在这里按母线侧解释，与上述 \(c,d\) 一致。若后续采用电池内部侧数据口径，需连同上限和输出定义一起转换，不能混用。

充放电实际还受到剩余容量、当前电量的限制：

\[
c_t\le\frac{10800-E_t}{\eta_c},\qquad
d_t\le\eta_d(E_t-1200).
\]

教学交互图“storage-balance.html”展示一个10分钟区间：给定净负荷、充放电指令和期初电量后，计算实际执行功率、需要购电量、富余量与期末电量。它不包含最优化，也不是附件求解结果。

**为什么低价充电、高价放电有时能省钱。**

低价时购入1 kWh，经储能周转后可替代高价时的 \(\eta_c\eta_d\) kWh购电。忽略其他限制和成本，此次周转的净节省为

\[
\eta_c\eta_d p_{\rm high}-p_{\rm low}.
\]

有利条件为

\[
\boxed{
p_{\rm high}>\frac{p_{\rm low}}{\eta_c\eta_d}.
}
\]

若单程各90%，低价0.4元、高价1元，理论上每充入1 kWh可节省 \(0.81-0.4=0.41\) 元。这里是人为教学价格，非题目实际优化结果。

但不能简单把电池在所有低价时段充满：中午可能有免费光伏需要留出空间，后续高峰也可能更值得保留电量。各时段通过 \(E_t\) 相互联系，因此适合统一优化。

**第一问：一个直接可解释的混合整数线性规划。**

在零点，把附件给出的负载和光伏预测视为本问规划输入，目标为

\[
\min \sum_{t=0}^{143}p_tq_t.
\]

电量平衡：

\[
\boxed{q_t+s_t+d_t=\ell_t+c_t+w_t,\qquad w_t\ge0.}
\]

它等价于题目“供电不可低于负载”的不等式，并明确记录富余量。

储能满足前述状态方程、容量和功率限制。为避免同一时段同时充放电，引入 \(z_t\in\{0,1\}\)：

\[
0\le c_t\le\bar c z_t,\qquad
0\le d_t\le\bar d(1-z_t).
\]

当 \(z_t=1\) 时只能充电或空闲，\(z_t=0\) 时只能放电或空闲。

第一问明确要求日初日末电量相同：

\[
E_{144}=E_0.
\]

以下教学代码采用附录初值6000 kWh。如果将第1问解释为长期周期运行并把周期初值作为变量，必须另说明该解释与附录初值的关系；不能在代码中悄悄改变初值。

目标和约束均为线性，只有充放电开关为0—1变量，因此是混合整数线性规划（MILP）。算法可通过线性松弛、分支定界等步骤求解；求解器会给可行解、最优性状态及相应界，不是随机试很多路线。

有些额外条件下可将互斥约束放松成LP，再消去同时充放电的循环，但不能仅凭“电价为正”宣称任意LP输出自动互斥。保守起点可直接保留开关变量，后续再验证是否值得简化。

**公式对应的教学代码。**

下面使用CVXPY表达第一问。输入数组必须已经是正确时间映射后的区间电量，不能直接传入附件中的kW列。代码未执行，求解器环境尚未针对本题验证。

```python
import cvxpy as cp

def plan_one_day(load_kwh, solar_kwh, price, e0=6000.0):
    # 输入均为同一自然日144个时段；price单位为元/kWh
    T = len(price)
    q = cp.Variable(T, nonneg=True)      # 计划购电
    c = cp.Variable(T, nonneg=True)      # 母线侧充电
    d = cp.Variable(T, nonneg=True)      # 母线侧放电
    w = cp.Variable(T, nonneg=True)      # 未利用富余
    E = cp.Variable(T + 1)              # 电池内部状态
    z = cp.Variable(T, boolean=True)    # 充/放开关

    constraints = [
        E[0] == e0,
        E[-1] == E[0],                  # 本约束用于第一问
        E >= 1200, E <= 10800,
        c <= (5000/6) * z,
        d <= (5000/6) * (1-z),
        E[1:] == E[:-1] + 0.9*c - d/0.9,
        q + solar_kwh + d == load_kwh + c + w,
    ]
    problem = cp.Problem(
        cp.Minimize(cp.sum(cp.multiply(price, q))),
        constraints
    )
    problem.solve(solver="SCIPY")
    if problem.status != cp.OPTIMAL:
        raise RuntimeError(f"尚未取得最优解：{problem.status}")
    return q.value, c.value, d.value, E.value, problem.value
```

`Variable`声明待求量，`constraints`把物理规则交给求解器，`Minimize`指定购电费用最小，`solve`调用算法求解。正式实现还需补齐输入检查、求解时限/最优性间隙、约束残差核验和模板导出。求解器报告optimal也不能替代逐项单位、能量与输出检查。

CVXPY的0—1变量与SciPy混合整数线性求解接口可见[CVXPY约束文档](https://www.cvxpy.org/tutorial/constraints/index.html)、[求解器文档](https://www.cvxpy.org/tutorial/solvers/index.html)。本说明没有安装或测试这些依赖。

**第二问：实际功率未知，为什么不能把全年实测直接代入第一问。**

2025年3月20日零点制定计划时，不能知道3月20日下午的实际光伏和负载。附件2虽然提供全年实测，它在回测中承担“后来发生了什么”的作用。

因此必须分开：

- 决策输入：零点以前已经观测的数据、日历信息等。
- 评估真值：当天逐步发生的实际负载和光伏。

第2问并未要求使用附件3，不能把第3问才给出的日内预报能力无说明地提前用于第2问。

一个可解释预测基线是“上一周同一天同一时段”：

\[
\hat L_{d,t}=L_{d-7,t}.
\]

也可用最近若干天同一时段平均：

\[
\hat L_{d,t}=\frac1m\sum_{j=1}^mL_{d-j,t}.
\]

负载候选模型可加小时、星期、过去1日/7日负载等特征；光伏可采用历史同一时段、日历和滞后特征。题目没有提供天气实测或未来天气预测，不能在文字中当作已给数据。若加入外部天气，必须核实当时可用的预报版本及来源。

预测结果进入储能调度，得到零点锁定的 \(q_t\)。实际执行时若不足，令紧急购电量为

\[
e_t=\max\{0,\ell_t+c_t-q_t-s_t-d_t\}.
\]

于是费用为

\[
\boxed{
C_2=\sum_t p_tq_t+5\sum_t p_te_t.
}
\]

原计划电量即使没有全部用上，也仍按计划量付费。第2问不能看到新实测后免费篡改原计划。

储能可以采用事先固定的安全计划，或明确采用随当前可观测状态反馈的实时策略；无论哪一种，都不能在当天结束后用整天真值反求一个“当时就知道”的最优电池轨迹。若10分钟数据只在区间结束时可得，应使用滞后信息或声明更细时间尺度的即时测量近似，不能无说明提前知道整个区间平均值。

**5倍紧急电价为什么会使计划偏保守。**

暂时忽略电池，考虑单个时段，真实净需求为随机量 \(R\)，计划量为 \(q\ge0\)，电价为 \(p>0\)。计划全额付费，多买的电没有残值：

\[
C(q)=pq+5p\,\mathbb E[(R-q)^+].
\]

其中 \((x)^+=\max(x,0)\)。若需求分布连续，

\[
C'(q)=p-5p\,\Pr(R>q).
\]

令导数为0：

\[
\Pr(R>q)=0.2,\qquad F_R(q)=0.8.
\]

所以此简化条件下最优计划是净需求的80%分位，而非平均值；若分位为负还需服从 \(q\ge0\)。离散分布用相应分位最优区间解释。

这个推导说明了不对称错误成本的作用。实际有电池、跨期电价和相关误差时，不能直接对每个时段套80%分位。

可用历史预测残差生成负载/光伏场景，以“计划费用+预期紧急费用”为目标比较安全裕量。不同场景在相同已知历史下必须采取相同决策；不能让每条场景提前知道整天路径再调电池，否则得到的是过于乐观的事后解。

**储电量在不同日期间必须连续。**

只有第1问明确规定日初日末相等。第2—4问不应每天自动重置6000，也不应无说明强加每日等量约束：

\[
E_{d+1,0}=E_{d,144}.
\]

初始6000只由题目指定在2025年1月1日零点。输出从2月1日开始，1月可作为初始训练与状态预热窗口，这是合理候选安排而非题目明文指定的唯一用途；2月1日的电量需由声明的1月运行或待机策略推导。

为避免有限规划窗口末尾把电池放空，可设置跨日展望、终端电量目标或剩余电能价值，但这是建模选择，不能称作题面要求。不同策略比较应统一终端处理。

**第三问：新预报如何进入滚动优化。**

每天0、6、12、18点可获得未来24小时逐小时光伏预报。附件3每条预报含“发布日期、发布时间、未来1至24小时”，应显式转换为

\[
(\text{issue time},\text{valid time},\text{lead time},\text{预测值}).
\]

例如6点发布的未来1小时预测对应7点，不是6点；到18点才发布的预报不能回填进零点决策。跨日有效时间可以进入次日的规划展望，但不能覆盖已经执行的动作。逐小时预测转10分钟电量时需明确插值与积分口径，端点不能用尚未发生的实测补齐。

滚动优化（MPC）的流程为：

1. 零点根据当时信息制定初始计划。
2. 执行到下一个可调整时点。
3. 读取实际电池状态和刚发布的预报。
4. 固定已执行时段，优化未来尚可调整的部分。
5. 只落实当前阶段决策，下一预报时点再更新。

使用当前状态、未来预测与有限时域优化并反复向前滚动，是MPC的基本思路，参见[do-mpc官方说明](https://www.do-mpc.com/en/latest/theory_mpc.html)。这里仅采用其方法思想，不表示必须使用该软件包。

**第三问的结算公式必须先澄清口径。**

设零点计划为 \(q_t^0\)，最终调整后的量为 \(q_t\)，增购和减购量为

\[
a_t=(q_t-q_t^0)^+,\qquad
b_t=(q_t^0-q_t)^+.
\]

增购部分电价1.5倍、减购违约价0.5倍在题文中明确；但取消部分原计划款是否退还、多轮调整按原计划还是上次计划结算，没有进一步明确。

若按“原计划款照付，调整费另加”的口径：

\[
\boxed{
C_{3,A}=\sum_t p_tq_t^0+
\sum_t(1.5p_ta_t+0.5p_tb_t)+
5\sum_t p_te_t.
}
\]

如果允许免费处理富余电，这个口径下减购不会节省成本：原计划费没退，反而多付违约费，保留原计划并处理富余电更便宜。这是该口径的数学结果，不能同时声称减购节省了原计划费用。

若取消部分退回原计划费用，并收取0.5倍违约费，则另一种口径是

\[
\boxed{
C_{3,B}=\sum_t p_tq_t^0+
\sum_t(1.5p_ta_t-0.5p_tb_t)+
5\sum_t p_te_t.
}
\]

例如 \(q^0=100,q=80,p=1\)，且没有紧急购电：前者110元，后者90元。该例仅用于解释结算差异，不能自行宣布其中一种已获题目确认。

多轮调整还要明确基准：如果结算按最终相对零点的差额，只结算最终差额一次；若逐次交易，就按每轮增量逐笔记录。不能每次重优化都把整份计划成本重新加进累计账单。

对本附件的正电价，以上两种口径都可用 \(a-b=q-q^0,\ a,b\ge0\) 作线性辅助表示：固定净差额后，同时增加 \(a,b\) 会增加费用，故最优解会回到对应正部。第二种口径同时增加二者的边际费用为 \(1.5p-0.5p=p>0\)。这一结论以当前分段费率和正价格为条件，多轮台账仍需另行定义，不能借辅助变量掩盖重复收费。

**是否应该使用所有日内预报，要由费用验证。**

预报更新有价值，不等于每次都值得修改购电合同。可以比较只用零点、增加6点、增加12点、增加18点，以及仅在预期节省大于调整代价时才交易等候选策略。

比较应在相同真实负载、光伏和价格序列上进行，并同时记录计划费用、紧急费用、增购费用、减购违约费用及所采用退款口径。不能只比较预测均方误差而忽略电池缓冲和交易费用。

新增信息也可仅用于改进电池运行而不调整合同。所谓“是否引入预报”，需区分读取信息与发生交易。

**第四问：电价也变动，信息时间边界更重要。**

附件4给全年实际电价。只读初查得到全部52560个价格为正，范围约0.0076—1.7936元/kWh；这属于输入范围核对，不是模型结果。

文件没有价格发布时间或未来价格预报字段。题面也未明确说明“零点就知道当天全部实时价格”，所以不能不加说明地把当天真实价格向量作为日前已知输入。

可以区分两类计算：

- 可实施策略：仅使用当前及历史价格预测未来价格，日前优化用当时可用信息，最终费用按实际结算价格计算。
- 完美价格信息参照：假设提前知道未来价格，分析信息价值；明确它是理想参照，不冒充实际可执行预测。

若采用场景方法，可以让价格、净负荷和光伏误差按场景共同变化：

\[
\min \mathbb E_\omega
\left[\sum_t p_t^{(\omega)}q_t+
5\sum_t p_t^{(\omega)}e_t^{(\omega)}+
\text{调整费用}^{(\omega)}\right].
\]

同一日前决策 \(q_t\) 不能随尚未发生的场景变化；储能和日内调整必须遵守逐时可观测性。第4问对应两条路线：不允许日内合同调整的result4-2，以及允许按第3问规则调整的result4-3。

**一段体现信息边界的回测伪代码。**

```text
初始化2025-01-01电量6000，声明1月运行/训练安排
按日期向前推进：
    只用当前零点以前已知的数据更新预测模型
    预测当天负载、光伏；第4问还预测未知的未来电价
    第3/4-3问仅加入此刻已经发布的光伏预报
    生成并锁定当天初始购电计划
    按时间区间向前执行：
        如到允许调整时刻，读取当次预报并优化未执行部分
        依据当时可测状态执行电池控制
        不足部分紧急购电；记录富余及实际费用
        更新真实电池电量与交易台账
    把日末电量传给下一日
    当天结束后才把当天实测加入后续训练历史
输出2月1日至12月31日及四个指定日期的结果
```

当天已经观测的过去时段可用于日内更新；伪代码中的日末训练入库是简化实现，不禁止因果的日内更新。核心限制是不能使用尚未发布或尚未发生的信息。

**预测误差与调度结果要分别验证。**

预测可用MAE、RMSE、分位覆盖率等。光伏夜间大量为0，不能直接依赖会除以0的MAPE；至少分日间与全日解释误差。数据划分要按时间向前滚动，标准化、特征选择和参数调节也只能使用此前数据，不能全年随机拆分。

调度应检查：

\[
\max_t\left|E_{t+1}-E_t-\eta_cc_t+d_t/\eta_d\right|,
\]

电量供需平衡残差、1200—10800范围、充放电上限、同段互斥、跨日连续、正确终端条件，以及费用台账和模板区间汇总的一致性。

比较层次可从无储能/简单规则、历史预测加MILP、风险裕量或场景优化、滚动调整开始。已知未来真值的“事后最优”仅可作理想成本参照，且需要统一结算规则与终端条件；不自动等价于所有在线模型的严格下界。

敏感性优先检查：单程/往返效率解释、初始及终端电量处理、预测安全裕量、调整费用口径、预报更新频率以及时间映射。经济结果必须来自实际求解与因果回测后才能写入正式论文。

| 问题 | 当前证据与处理 |

| 10分钟时间映射 | 原始功率时刻与结果模板首末区间不完全一致；保留原件，另建映射，不能默改 |

从选题角度看，C题有清晰的“预测—优化—回测”结构，单日电池模型可用线性或混合整数规划解释，主要挑战集中在数据时序、预测误差引起的经济风险、合同调整规则和全年状态连续性。它的验证依靠真实附件的因果回测和结果表，不需要B题指定的模拟器；当前没有实际求解成绩可用于断言最终优劣。
