**6. 参考结果与我们的差异从何而来**

两边采用的主要连续结构相近：一维径向、有效显热、Ceq 直接等效、相同经验物性、同平台延拓、Q4 仿射材料收缩。差异主要在非线性界面离散与时间算法：参考采用调和平均和 CN/Picard；我们已比较过同类调和方案，并转向含水率 Kirchhoff 势的保守面通量及 BDF/解析 Jacobian。

早期端点交叉核对很一致。参考 Q1 1800 s 与本队 Q1 N=3200 样本的中心/表面温差均小于 7×10⁻⁷°C，表面浓度差约 3.22×10⁻⁶；Q2 3 h 与本队 Q23 N=1600 的中心/表面温差小于 5×10⁻⁷°C，浓度差小于 9×10⁻⁷。这些一致性支持两套模型初期实现接近，不证明所有时间和位置均具同等误差。

**7. 验证报告不能支持“全场四位小数可靠”**

确定的问题与边界如下：

1. README 和正文第 6.1 节把 2.35×10⁻⁴°C 称为低于 10⁻⁴ 的报告精度，算术上相反。四位小数的半舍入单位为 5×10⁻⁵；该误差为其 4.7 倍。常 D 水分校验报 3.89×10⁻⁴，同样不能支持全场四位准确。
2. verify.v1/v2 默认 N=200，生产 N=400；README 未充分区分这个参数差别。不能因 N 加倍就默认每一处误差恰好除以 4，尤其表面初始层。
3. v1/v2 的索引 k=int(t)−1 忽略 simulate 已在第 0 项保存 t=0，实际检查时刻为 59/119/299…而非声明的 60/120/300…。它随后用 t_act 同步解析时间，因此不是错时相减；但“覆盖哪些检查点”的声明不准确，且没有检查每个逐秒输出。
4. verify.v4 的网格/时间比较只取 Q1 t=1800 s 的中心与表面温度，完全不能代表初始表层、全部浓度、Q2—Q4 的全场。正文补充 Q2 3 h 单个最大值也不足以补齐。
5. v3 默认仅 Q1/1800 s；外部输出采样梯形积分还包含时间求积误差。这个例子的残差小，不自动证明 Q4 移动几何或所有非线性算例无虚假源。代码又会截负 C 为 0，需记录是否触发，不能只称无条件守恒。
6. v5 是 Q1 常热物性、中心点的有限圆柱/平板乘积热解，并没有计算非线性湿场和 Q3/Q4 达标事件。打印结论“端面对烘干时间影响更小”不是该程序直接计算的结果。L/R=12.5 也应称长半径比，常见长径比 L/(2R)=6.25。
7. 特征级数 n_terms=40 与 z_max=100 同时使用，实际根数受 z_max 限制；需检查实际项数和级数截断，而不是只凭请求项数/根残差宣称解析参考已收敛。未在本轮运行它。
8. 验证函数主要打印误差，没有根据声明的精度阈值产生失败状态。存档中缺少与生产源码/输入哈希绑定的 V1—V5 机器可读验收日志。本轮已读的文档数字可以作为他方报告，不能转为本队复现结论。

**8. 敏感性结论：可作为待检验现象，不能直接采纳工程建议**

参考 sensitivity.json 的基准是 N=200、58.95178396 h，和 README 主要 N=400 的 57.6868 h 不同；文档部分段落有写 N，但总评不能混用。N200→N400 本身使基准减少 2.1458%，已经大于其若干 0.01%—1.8% 的物理情景差异。

其中“β 加倍反而延时 5.816%”“Ceq 加 20% 反而提前 1.797%”“存在最优 β、后期应减弱排湿”均来自 N200 调和面单网格结果，没有为每个扰动情景单独做表层/事件收敛。我们已发现该离散对表层低 D 强烈敏感；本队 Kirchhoff 的 β×0.8/×1.2 情景分别得到约 59.1693/56.4335 h，至少在这一局部范围未出现参考所称的趋势。倍率不同，不能据此严格否证其 β×2 分支，但足以要求重新验证，不能直接据粗网格非单调作工艺优化建议。

其“Ceq 从湿基转干基”只有 w/(1−w) 变换，没有补上干空气到干药材之间的吸附等温关系。这仅测试一种小幅数值变化，不能据 1.29% 的差就宣布空气/材料基准歧义影响有限。

平台与末段均值的两个边界相距本来就极小；第三个指数平滑试验还同时改变了观测区间内的输入。这些场景差小只支持所选相近输入下的局部结果，不能证明任意 4 h 后过程“完全不敏感”，也不能声称已识别真实后期环境。

D×0.5/×2 是人为扰动，不是题给 D 的测量误差分布。因此“总不确定度由 D 决定、其他影响都在 1% 内”没有统计或完整物理依据。潜热、气固平衡、真实密度与收缩反馈并未被上述参数表覆盖。

2×2 物性/几何对照是值得采用的结构；但所有对照都应重跑至各自收敛、保持明确同一物理口径。参考正文正确说 Q3→Q4 差不能全归因于收缩，README 开头及 results.py 最后一句却仍称“收缩使时间缩短 11.40%”，内部表述需要统一。给定 R(t) 下的敏感性也不能当作新工况收缩反馈已预测。

- 第 9.2 节称经验 ρ 与固定骨架的矛盾“通过恰当约去 ρd 回避”。约去仅简化水分方程，不能修复真实湿密度与干质量/几何的矛盾；我们已有约 19.5 h 必要半径界及非仿射/长度替代推导。
- 能量推导把 ρcp=ρd(cd+Ccw) 当作严格关系，又同时使用题给经验 ρ 和守恒的固定/仿射 ρd，没有解释相容性；采用一致的组分焓可推出温度式，但不能宣称原经验密度同时严格成立。
- 文稿用 jw≈10⁻⁶ 估算携焓 4 W/m³ 和潜热 2.4 W/m²，实际代码 flux_C=β(Cs−Ceq) 的单位为 m/s，而非 kg/(m²s)。若作为真实水质量通量，缺少ρd因子，约数百倍量级。不能据此证明携焓低三个数量级或潜热仅 2%。
- 潜热必须与真实气固边界相容。我们已有“低于环境露点却继续蒸发”的条件性压力测试反证，参考包没有解决该缺口。
- 将末段波动判断为“50°C+测量噪声”并称由数据本身确定，是比数据支持更强的结论；没有校准/重复试验能区分控制波动与测量误差。
- 终温显示 50.0000 是所选无源、平台边界模型的预期后期极限，并非实测热力学验证；温度可以在环境下降的短时段高于同时刻空气温度，最大值原理约束的是初值/边界历史范围，不能混为永远不超过当时空气。
- “N 是 20 的倍数消除全部插值误差”仅适用于固定 R、固定输出半径恰落节点。Q4 的 r/R(t) 随时间变化，通常仍需空间插值；临界事件和非整数时刻也有时间插值。
