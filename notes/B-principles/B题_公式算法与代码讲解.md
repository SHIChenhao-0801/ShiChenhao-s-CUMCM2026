**先理解整道题在做什么。**

机器狗从原点出发，在平面中选择位置和频道。模拟器返回“无信号”“距离很近”或带误差的方位角。程序据此判断下一步去哪里、是否继续检测、是否尝试清除以及何时结束。在确保所有源被清除的前提下，虚拟总耗时越短越好。

| 问题 | 已知输入 | 需要输出 | 核心数学 |
|---|---|---|---|
| 1 | 检测点坐标、同一源的多个示向度 | 多边形定位区域的直径算法；同直径圆能否覆盖 | 半平面交、凸多边形直径、最小包围圆 |
| 2 | 全向源的一次检测位置和示向度 | 第二检测点策略及候选区域 | 有界误差、几何交会、稳健选点 |
| 3 | 10—16个全向源，实际数量未知 | 自动搜索定位清除算法、演练统计、三次正式结果与日志 | 覆盖、在线决策、路径和测量成本优化 |
| 4 | 全向和定向源混合，实际数量及朝向未知 | 对定向遮蔽有效的算法、演练统计、三次正式结果与日志 | 位置与朝向不确定性、完整性证明 |

题目提供的是简化后的测量和动作规则。程序不能读取测试案例中的真实位置、数量和接收半径，也没有连续场强数值接口可供自行反演距离。

**必须先掌握的规则。**

| 量或规则 | 题设 |

返回角度保留两位小数。下文纯题面几何采用1°；涉及数值程序的保守包络示例采用1.01°，后者是我们人为增加的裕量，不能改写成题设误差界。

**第一问：为什么测一次角度只能得到一个扇形范围。**

设源为 \(G=(x,y)\)，第 \(i\) 个检测点为 \(S_i=(x_i,y_i)\)，读数为 \(\theta_i\)，误差上界为 \(\delta=\pi/180\) 弧度。真实角度

\[
h_i(G)=\operatorname{atan2}(y-y_i,x-x_i)
\]

满足圆周意义上的误差界

\[
|\operatorname{wrap}(h_i(G)-\theta_i)|\le\delta.
\]

wrap把角度差化到 \([-\pi,\pi]\)，避免把359.5°与0.5°错误地视为相差359°。

角度提供方向，没有给出距离，因此一次读数对应两条边界射线之间的窄楔形。定义

\[
d_i^-=(\cos(\theta_i-\delta),\sin(\theta_i-\delta)),\quad
d_i^+=(\cos(\theta_i+\delta),\sin(\theta_i+\delta)).
\]

二维叉积为 \(\operatorname{cross}(a,b)=a_xb_y-a_yb_x\)。向量 \(G-S_i\) 在下边界左侧、上边界右侧，等价于

\[
\operatorname{cross}(d_i^-,G-S_i)\ge0,\qquad
\operatorname{cross}(d_i^+,G-S_i)\le0.
\]

这两个约束的交集就是朝向前方、张角为2°的楔形。把它们改写成便于计算的半平面 \(a^\mathsf TG\le b\)：

\[
a_i^-=(\sin(\theta_i-\delta),-\cos(\theta_i-\delta)),
\quad b_i^-=(a_i^-)^\mathsf TS_i,
\]

\[
a_i^+=(-\sin(\theta_i+\delta),\cos(\theta_i+\delta)),
\quad b_i^+=(a_i^+)^\mathsf TS_i.
\]

多次检测后，真实源必须同时满足全部约束：

\[
P=\bigcap_i W_i.
\]

因此交会定位就是计算半平面交。半平面是凸集，交集仍是凸集；当交集非空且有界时，它是凸多边形，也可能退化成线段或点。

需要检查退化情形：观测方向几乎平行时，纯角度交集可能很长或无界；观测矛盾、单位混淆或数值误差可能产生空集。不能用一个随意的大方框截断后，把方框产生的边界当作真实定位边界。

如果使用全题给出的源位置先验，可另取

\[
K=P\cap B(0,1800)\cap\bigcap_i B(S_i,1500).
\]

这里 \(B(c,R)\) 表示闭圆盘。有信号说明距离不超过1500米，但不说明某源的真实接收半径就是1500米。加入圆盘后的边界可能含圆弧，应与第一问的纯多边形区分。

若程序需要始终使用多边形，可以用圆的外切多边形作为保守外包，不能用内接多边形而误删可能的真实源。均匀取 \(N\) 个单位法向量 \(n_k\)，约束 \(n_k^\mathsf T(G-c)\le R\) 得到外切多边形，最大径向松弛为 \(R(\sec(\pi/N)-1)\)。

**半平面裁剪算法怎样写。**

已知一个按边界顺序排列的凸多边形，对每条边 \(p\to q\) 检查两端是否满足 \(a^\mathsf Tx\le b\)。两端同侧时保留或删除；一内一外时加入交点。

令 \(f(p)=a^\mathsf Tp-b\)，交点写作 \(p+t(q-p)\)。代入直线方程可得

\[
t=\frac{f(p)}{f(p)-f(q)},\qquad
z=p+t(q-p).
\]

下面是教学代码，点用二元组表示，输入多边形必须已知有界，并按顺时针或逆时针排列：

```python
from math import sin, cos, radians, hypot

def clip_halfplane(poly, a, b, tol=1e-9):
    """保留 a·p <= b+tol 的部分；a 为单位法向量。"""
    if not poly:
        return []
    out = []
    for p, q in zip(poly, poly[1:] + poly[:1]):
        fp = a[0]*p[0] + a[1]*p[1] - b - tol
        fq = a[0]*q[0] + a[1]*q[1] - b - tol
        pin, qin = fp <= 0, fq <= 0
        if pin:
            out.append(p)
        if pin != qin:
            t = fp / (fp - fq)
            out.append((p[0] + t*(q[0]-p[0]),
                        p[1] + t*(q[1]-p[1])))
    return out

def add_bearing(poly, station, bearing_deg, error_deg=1.0):
    theta, delta = radians(bearing_deg), radians(error_deg)
    lower = (sin(theta-delta), -cos(theta-delta))
    upper = (-sin(theta+delta), cos(theta+delta))
    for a in (lower, upper):
        b = a[0]*station[0] + a[1]*station[1]
        poly = clip_halfplane(poly, a, b)
    return poly

def polygon_diameter(poly):
    if not poly:
        raise ValueError("定位集合为空，先检查观测与数值处理")
    return max((hypot(p[0]-q[0], p[1]-q[1])
                for i, p in enumerate(poly)
                for q in poly[i+1:]), default=0.0)
```

`add_bearing`把一次检测转换为两次裁剪；反复调用就把各次检测共同允许的区域留下来。`tol`仅处理浮点误差，不应当代替角度读数的舍入包络；这里把半平面向外移动极小距离，并在内外判定与交点计算中使用同一个边界。

例如从 \([-1800,1800]^2\) 开始是对题目圆域的安全外包，可以用于保守清除判据；但若方框边界参与了结果，就不能把结果直径称为纯角度交集的精确直径。

若定位多边形有 \(m\) 个顶点，最后一段枚举所有顶点对，复杂度 \(O(m^2)\)。本题观测数量通常不大，先采用这种容易核验的方法即可。

**为什么直径只需要比较顶点。**

设 \(P=\operatorname{conv}\{v_1,\ldots,v_m\}\)。任意两点

\[
p=\sum_i\alpha_i v_i,\quad q=\sum_j\beta_jv_j,\quad
\alpha_i,\beta_j\ge0,\quad\sum_i\alpha_i=\sum_j\beta_j=1.
\]

于是

\[
\|p-q\|
=\left\|\sum_{i,j}\alpha_i\beta_j(v_i-v_j)\right\|
\le\sum_{i,j}\alpha_i\beta_j\|v_i-v_j\|
\le\max_{i,j}\|v_i-v_j\|.
\]

顶点本身也在区域中，因此上界可达到：

\[
\boxed{D(P)=\max_{i,j}\|v_i-v_j\|.}
\]

**同直径的圆不一定能覆盖定位区域。**

考虑边长40米的等边三角形。它的区域直径为40米，但最小包围圆半径为

\[
r_*=\frac{40}{\sqrt3}\approx23.094\text{米}>20\text{米}.
\]

因此不存在半径20米的圆把它全部覆盖。这同时说明：后续清除策略不能仅凭“定位域直径不超过40米”保证成功。

真正对应清除条件的是

\[
\boxed{r_*(P)=\min_z\max_{g\in P}\|z-g\|.}
\]

若 \(r_*(P)\le20\)，到最优圆心 \(z_*\) 清除就有保证。圆盘是凸集，覆盖全部多边形顶点即覆盖整个多边形。

最小包围圆由至多3个支撑点确定。对小规模顶点集，可以枚举两点构成的直径圆、三点构成的外接圆，检查是否覆盖所有顶点，再取半径最小者；单点、共线、重复点另处理。更高效的实现可采用随机增量算法。此性质及Welzl算法可参见[CGAL官方最小包围圆文档](https://doc.cgal.org/latest/Bounding_volumes/classCGAL_1_1Min__circle__2.html)。

等边三角形反例也能由合法窄角度观测形成：取顶点 \((-20,0),(20,0),(0,20\sqrt3)\)，第一站为 \((-1100,0)\)，读数1°，两边界为0°、2°。再将站点与楔形一起绕三角形中心旋转120°、240°。三条下边界构成三角形的三条边，三条上边界均在外侧，交集恰为该三角形。站点均在题域内，距离也可满足1500米接收上限。这是几何构造，未用于模拟器测试。

**第二问：为什么第二次不能随便换个位置。**

第一次的角度误差会随距离放大。在沿读数方向距离 \(d\) 的截面处，横向半宽为

\[
w(d)=d\tan\delta.
\]

当 \(d=1000\) 米、\(\delta=1^\circ\) 时，半宽约17.455米，整个截面宽约34.91米。如果第二次的示向线与第一次几乎平行，两个狭长范围仍然会产生很长的交集。

一阶局部分析中，两条观测线的求交相当于解一个二元线性方程组；系数矩阵行列式的绝对值为 \(|\sin\phi|\)，\(\phi\) 为两观测方向夹角。因此误差放大含有

\[
\frac1{|\sin\phi|}
\]

这一因子。夹角接近0°或180°时不利；在观测距离相当等条件下，接近90°通常有利。距离更近也会减少角度误差带来的横向位置不确定性，因此90°不是忽略距离与移动成本后仍成立的万能最优解。

交互图：[bearing-geometry.html](<D:/Document/数学建模/2026CUMCM/notes/B-principles/bearing-geometry.html>)。图中两站离教学目标均为800米，误差锥严格采用±1°，可拖动15°—165°交会夹角。显示的是计算出的定位多边形和最远顶点对。教学目标坐标仅为展示几何关系，真实任务并不知道源的位置；图中数值不是演练成绩。

**第二站的接收保证与候选区域可以严格推导。**

一次收到全向源信号后，以保守包络表示首次可能位置：

\[
K_1=B(0,1800)\cap W_1\cap B(S_1,1500).
\]

因为每个源接收半径至少1000米，若第二站 \(Q\) 满足

\[
\max_{g\in K_1}\|Q-g\|\le1000,
\]

无论真实源在 \(K_1\) 的哪里，都一定还能收到信号。因此安全候选区域为

\[
\boxed{\mathcal Q_{\rm safe}=\bigcap_{g\in K_1}B(g,1000).}
\]

若 \(K_1\) 用安全外包凸多边形表示，检查最远顶点即可给出充分保证；实际可行候选域可能更大。

可以进一步给出一个不依赖复杂优化的显式构造。令首次位置为 \(S\)，读数方向与其垂直方向为

\[
e=(\cos\theta,\sin\theta),\qquad n=(-\sin\theta,\cos\theta).
\]

取我们增加裕量后的 \(\delta_{\rm impl}=1.01^\circ\)。因为接收距离不超过1500米，真实源必属于矩形

\[
G=S+ue+vn,\qquad
0\le u\le1500,\qquad |v|\le w=1500\sin\delta_{\rm impl}\approx26.44.
\]

第二站写为 \(Q=S+ae+bn\)。利用正交坐标及矩形端点，可得

\[
\max_{\text{外包矩形内 }G}\|Q-G\|^2
=\max\{a^2,(a-1500)^2\}+(|b|+w)^2.
\]

故一个具体的保守候选域是

\[
\boxed{\max\{a^2,(a-1500)^2\}+(|b|+w)^2\le1000^2.}
\]

例如

\[
\boxed{Q_\pm=S+750e\pm500n}
\]

满足

\[
\|Q_\pm-G\|\le\sqrt{750^2+(500+w)^2}\approx916.3<1000.
\]

也就是沿第一次读数方向前进750米，再向左或右偏移500米。两者都有全向接收保证，并形成侧向基线。若恰进入5米内，得到near后直接清除。这是可解释的安全候选，不是最优位置结论，也不能直接给定向源同样的接收保证。

**如何在候选域中继续优化。**

对每个候选站 \(Q\)，考虑所有可能的真实源 \(g\in K_1\) 和新误差 \(|\eta|\le\delta\)，新读数为 \(\theta_2=h_Q(g)+\eta\)。定位效果可以用新的最小包围圆半径评价。一个稳健目标是

\[
\min_{Q\in\mathcal Q_{\rm safe}}
\sup_{\substack{g\in K_1,\ |\eta|\le\delta\\\|Q-g\|>5}}
r_*\!\left(K_1\cap W(Q,h_Q(g)+\eta)\right).
\]

距离不超过5米的情形直接进入near并清除，可将后续定位损失记作0；以上上确界仅表示正常角度反馈分支，若该分支为空则取损失0。实际策略还需加入移动耗时，可以把该目标与距离作多目标比较，或在权重单位明确后加权。有限采样得到的是近似评分，不能自动当作连续最坏情形证明。

还可以用最小二乘快速估计一个点。令 \(n_i=(-\sin\theta_i,\cos\theta_i)\)，观测中心线为 \(n_i^\mathsf T(G-S_i)\approx0\)。把 \(n_i^\mathsf T\) 逐行放入矩阵 \(A\)，把 \(n_i^\mathsf TS_i\) 放入向量 \(b\)，得到

\[
\hat G=\arg\min_G\|AG-b\|^2.
\]

满列秩时形式解为 \((A^\mathsf TA)^{-1}A^\mathsf Tb\)，数值实现宜用QR或SVD求解而非显式求逆。它可以生成初始位置或候选站，但只是点估计，不能取代整个可行域及清除保证。

题目只给有界角误差，没有给独立高斯分布或同分布保证。若另行采用概率模型、Fisher信息或期望信息增益，需要明确新增假设，并用实际演练检查效果。反复在同一位置测量取平均并不能消除题设中的固定误差。

**第三问：总时间模型和自动决策。**

设总移动距离为 \(L\)，被接受的检测动作数为 \(M\)，实际检测换台次数为 \(Q_{\rm sw}\)，被接受但失败的清除次数为 \(F\)，成功清除的不同源数为 \(K\)。则

\[
\boxed{T_{\rm virtual}
=\frac L5+5M+Q_{\rm sw}+3F+5K.}
\]

单位均为秒。`/clear`中的channel只指定目标，不会改变测向机当前频道，也不会收取换台时间。

题目的两项演练统计为

\[
\text{清除比例}=\frac KN,\qquad
\text{平均定位清除时间}=\frac{T_{\rm virtual}}K.
\]

其中 \(N\) 是该案例源总数；演练结束后模拟器才显示它。正式测试接口不会给出 \(N\)，不能拿未知真值设计提前退出规则。若 \(K=0\)，平均时间无定义，应标明，而不能填写0。

约束首先是保证全部清除。在未保证完整性时，单独降低 \(T/K\) 会诱使算法只清除容易找到的源，不能满足题意。

可采用清晰的分层算法：

1. 全域发现：按有覆盖证明的站点集合检测尚未清除的频道。
2. 局部定位：同频道保存多个观测，逐步裁剪位置可行域。
3. 主动选点：选择能改善定位并控制移动、检测成本的下一站。
4. 清除：near时原地清除；最小包围圆半径不超过20米时去圆心清除。
5. 查漏与退出：继续完成必要覆盖，直到每个频道都已清除或被证明不存在未清除源。

实际还可以把相近目标一起处理、删除已清除频道、减少往返和没有信息增量的测量。局部“预计不确定性缩减/新增时间”评分可作启发式，但“预计”的依据需要说明，不能称为全局最优。

**第四问：定向源为何更难。**

设源 \(G\) 的未知发射朝向是单位向量 \(a\)，检测位置为 \(P\)。发射半平面条件为

\[
a^\mathsf T(P-G)\ge0.
\]

这里是“源指向机器狗”的向量；测得的示向度却是“机器狗指向源”的方向，不要把两者写反。

全向源在1000米以内一定有信号，因此对尚未清除的频道，第三问一次no_signal可以排除闭圆盘 \(B(P,1000)\) 内的源位置。第四问则不行：可能距离很近，但位于发射背面。

如果维护位置与朝向的联合可能集合，定向源的no_signal提供保守必要条件

\[
\|P-G\|>1000\quad\text{或}\quad a^\mathsf T(P-G)<0.
\]

对于第4问的混合类型，需要保留“全向/定向”类型分支，不能把全部未知频道预先当成某个已知定向类型。正向观测对定向分支增加 \(a^\mathsf T(P-G)\ge0\)，并对所有分支增加测向楔形与1500米距离上限。

局部策略应保留可替代的观测位置。如果只沿某条直线搜索，定向源可能一直在背面，导致漏检；仅凭“最近几次没有新源”退出也没有完整性依据。

**一个同时适用于第三、四问的有保证发现基线。**

取间距 \(s=500\) 米的站点集合

\[
\mathcal P=\{(500i,500j):i,j=-5,\ldots,5\}.
\]

共有121个站点，覆盖 \([-2500,2500]^2\)。按蛇形访问，每站检测全部尚未清除频道。外围点利用了机器狗可以走出目标圆域这一题设。

证明任何定向源都会在其中某站被发现：任取源位置 \(G\)，取最近格点 \(q\)，则

\[
\|q-G\|\le s/\sqrt2.
\]

对任意单位朝向 \(a\)，至少一个坐标分量满足 \(|a_i|\ge1/\sqrt2\)。选择相应的轴向邻点

\[
P=q+s\,\operatorname{sign}(a_i)e_i.
\]

有

\[
a^\mathsf T(P-G)\ge-\|q-G\|+s|a_i|\ge0,
\]

\[
\|P-G\|\le s+s/\sqrt2\approx853.55<1000.
\]

因此该点既在发射半平面内，又在最低接收距离内，一定能检测到。算法会访问全部格点，因此不必预知哪个点对应未知朝向。源坐标绝对值不超过1800，最近格点坐标绝对值至多2000，所用邻点坐标绝对值至多2500，均包含在集合中。

这证明了“不漏发现”，还需要保证“被发现后能够清除”。下一段补上这个环节。方格基线不是速度最优方案，但可以用作比较和查漏的依据。

**即使角度难以进一步收敛，仍有有限次必清除的后备方案。**

首次获得direction后，前文已证明真实源位于旋转矩形 \(0\le u\le1500,\ |v|\le w<26.45\)。安排两排清除位置：

\[
\boxed{
P_{k,\pm}=S+(12.5+25k)e\pm15n,\quad k=0,\ldots,59.
}
\]

沿纵向每25米放一个点，横向两排分别在+15米和−15米。对矩形内任何源，总存在候选点使

\[
|\Delta u|\le12.5,\qquad |\Delta v|\le15.
\]

于是

\[
\|P_{k,\pm}-G\|\le\sqrt{12.5^2+15^2}
\approx19.526<20.
\]

因此逐个清除、成功即停，最多120个候选点必有一个成功。光学清除不受辐射朝向影响，故对定向源也成立。若方向反馈与题设不一致、请求失败或程序漏执行，则不满足证明前提，不能仍然声称必然完成。

教学代码如下，仅生成清除候选位置：

```python
from math import cos, sin, radians

def fallback_clear_points(sx, sy, bearing_deg):
    angle = radians(bearing_deg)
    ex, ey = cos(angle), sin(angle)   # 示向方向
    nx, ny = -ey, ex                 # 垂直方向
    for side in (15.0, -15.0):
        indices = range(60) if side > 0 else range(59, -1, -1)
        for k in indices:
            u = 12.5 + 25*k
            yield (sx + u*ex + side*nx,
                   sy + u*ey + side*ny)
```

`yield`依次给出候选点；第一排从近到远，第二排从远到近，以免每次折返。调用端在每点对相同频道发送一次`/clear`，收到`clear_result="success"`立即停止；网络失败要按协议处理，不能视为已到达该点。

这种方案适合给完整性兜底。高效方案应优先通过第二、第三个观测缩小可行域，在有保证的圆心附近一次清除。

**保底方案的理论虚拟时间，与真实演练成绩有何区别。**

从原点先到 \((-2500,-2500)\)，再蛇形访问121个站点，基础探索路长为

\[
L_{\rm scan}=2500\sqrt2+120\times500\approx63535.53\text{米}.
\]

如果每站都按1—20检测，共2420次检测、2419次换台，则只计算探索的虚拟耗时为

\[
T_{\rm scan}=L_{\rm scan}/5+2420\times5+2419
\approx27226.11\text{秒}=7.56\text{小时}.
\]

上面两排清除位置按蛇形走完并返回发现站，长度至多

\[
2\sqrt{12.5^2+15^2}+2\times1475+30\approx3019.05\text{米}.
\]

至多119次失败加1次成功，操作耗时362秒。因此每个源的清除附加虚拟耗时至多约965.81秒；最多16个源，总理论上界约11.86虚拟小时。中途成功、停止扫描已清除频道可以减少耗时。协议没有纯移动指令，实际下一动作可直接去下一检测位置，其直线距离不超过上述经发现站返回的保守计费路线。

这些是根据题设逐项推导的上界，不是实际运行记录。它们只说明该基线不触及100小时虚拟上限；最坏约4342次HTTP请求（含进入退出），仍需实际验证能否在现实20分钟内执行、日志是否小于2MB，以及网络和异常恢复是否可靠。

**什么情况下才允许算法宣布全部清除。**

可以采用以下任一充分条件：

- 覆盖证明要求的检测已经对全部未清除频道完成；所有曾发现的源都有有效且去重的清除成功记录，因此每个频道都“已清除”或“经覆盖证明没有未清除源”。
- 已经成功清除16个不同频道的源；题目总数不超过16，故可提前结束。

清除10个、清除当前已知全部目标、长时间没有新发现，都不能单独证明任务完成。`/exit`返回`user_exit`仅表示主动退出，不是模拟器给出的“全部清除认证”。

**算法如何通过模拟器执行。**

程序对本机 `http://127.0.0.1:2026` 发送HTTP POST，四个端点为：

| 端点 | 功能 |
|---|---|
| `/enter` | 进入本局，获取实际剩余现实运行时间 |
| `/measure` | 自动移到position，在channel检测 |
| `/clear` | 自动移到position，清除指定channel的目标 |
| `/exit` | 主动结束本局 |

检测请求示意：

```json
{
  "arena_id": "default",
  "robot_id": "<当前登录参赛队号>",
  "request_id": "measure-0001",
  "position": {"x": 300, "y": 400},
  "channel": 1
}
```

只有`measure_result="direction"`时才读取`svd_deg`。`near`直接清除；`no_signal`更新搜索记录。清除返回的字符串是`success`或`no_target_in_range`。

完整控制循环的伪代码：

```text
等待模拟器界面显示接口就绪
enter；保存实际剩余现实时间、虚拟限额
初始化位置(0,0)、测向机频道1、20个频道的记录
重复：
    检查是否已有充分的全部清除证据
    若有，exit并结束
    依据覆盖进度和已有观测，决定下一动作
    为新动作创建新request_id，并固定完整请求内容
    串行发送，等待完整HTTP响应
    若网络超时：仅以原ID、原内容重试同一动作
    检查HTTP状态及accepted；仅在accepted=true时更新动作状态
    保存响应、位置、实际测向频道、累计虚拟时间
    按direction/near/no_signal或clear_result更新每频道状态
    检查现实时间余量与异常；异常结束必须如实记录未完成情况
```

请求必须串行，不能并发指挥同一只机器狗。正常串行合法动作没有请求速率上限；题目的检测5秒只增加虚拟时间，不要每测一次就在现实中sleep(5)。

网络重试复用同一ID与相同内容，模拟器返回第一次响应，不重复计时；新动作必须用新ID。HTTP 200不代表业务已执行，还需检查`accepted=true`。拒绝响应中的`virtual_time_s=0`不能覆盖最近一次有效虚拟时钟。

建议每频道维护：状态、有效测向观测、可能位置集合、已检测站点、清除尝试及成功证据。请求、响应和本地状态更新需能够追踪；重复响应不能增加清除计数。
